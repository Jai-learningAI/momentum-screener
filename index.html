Refresh data

Data refreshes automatically every weekday at 5 PM IST. The repo owner can also refresh it on demand, which takes about 2–5 minutes.

Owner setup (one time)

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories, then pick .
  3. Permissions: Actions: Read and write and Contents: Read-only. Generate, then paste it here.

The token is saved only in this browser and sent only to api.github.com.
